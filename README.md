# Карта интерфейсов

Интерактивная визуализация осей, по которым различаются интерфейсы. Идея простая:
классификация «класс задачи × модальность» слишком груба — два интерфейса совпадают
по обоим уровням и остаются совершенно разными продуктами. Значит, интерфейс полезнее
описывать не ящиком в списке, а вектором координат.

Страница показывает три вещи.

**Плоскость.** Две главные оси — что делает пользователь (оценка состояния мира против
его изменения) и насколько открыто пространство вариантов. На них ложится классическая
четвёрка observation / exploration / transaction / generation. Навигация нарисована
пунктирной рамкой вокруг плоскости, а не пятым квадрантом: это мета-слой, способ попасть
в нужную клетку, налог на размер продукта.

**Оси, которых в плоскости нет.** Десять независимых координат: инициатива,
темпоральность, уровень делегирования, экспертиза и частота, ставка и обратимость,
доверие к контрагенту, режим внимания, кардинальность, единица управления, форма вывода.
Ни одна не сводится ни к классу задачи, ни к модальности.

**Вычисляемое следствие.** Три оценки — насколько выгоден язык на входе, насколько выгоден
язык на выходе и можно ли отдать модели сам коммит — считаются формулами из координат
архетипа, а не проставлены вручную. Это и есть смысл векторного представления: ответ
выводится из положения точки.

Пятнадцать архетипов (дашборд, пейджер алертов, SQL-консоль, платёжная форма, графический
редактор, чат-ассистент, панель надзора за агентом и другие) расставлены по всем осям.
Выбор архетипа перемещает маркеры на всех шкалах сразу; наведение на второй кладёт рядом
призрачный маркер для сравнения.

## Публикация на домен

Готовый статический сайт лежит в `publish/site/` (и архивом в `publish/intranet-map.zip`).
Node на сервере не нужен: залейте содержимое `publish/site/` в корень домена.
Подробности — в `publish/ПРОЧТИ-МЕНЯ.txt`.

На свой Mac:

```bash
cp -R publish ~/Desktop/intranet-map
```

## Запуск

```bash
npm install
npm run dev
```

Откройте <http://localhost:43127>.

Сборка и проверки:

```bash
npm run build
npm run lint
npx tsc --noEmit
```

## Где что лежит

| Путь | Что там |
| --- | --- |
| `src/lib/interface-map.ts` | Определения осей, зон, архетипов и формулы вердиктов |
| `src/components/quadrant-map.tsx` | SVG-плоскость с рамкой навигации |
| `src/components/axis-spectrum.tsx` | Одна шкала с маркером и призраком сравнения |
| `src/components/verdict-panel.tsx` | Три вычисляемые оценки пригодности языка |
| `src/app/page.tsx` | Композиция страницы |

Значения координат — авторская экспертная оценка, а не измерение. Их смысл в относительном
положении архетипов друг относительно друга: карта нужна, чтобы спор о том, «что лучше»,
превращался в вопрос о том, в какой точке пространства вы находитесь.

## Стек

Next.js 16 (App Router), TypeScript, Tailwind CSS v4, shadcn/ui. Внешних зависимостей для
графики нет — плоскость и шкалы нарисованы вручную на SVG и CSS.
