# Паттерны и механики интранета

Интерактивная карта для продуктовых менеджеров: куда в корпоративном интранете
встраивать языковые механики. Это не каталог экранов и не очередь внедрения по
часам — восемь повторяющихся форм работы, пять принципов и десять механик
ретрофита.

Человек узнаёт свой экран в одном из паттернов («выборка по описанию», «чистый
лист», «одно правило на много строк») и получает механику, которая ложится на
уже существующую таблицу или форму. Отдельного окна чата среди механик нет:
язык держится на входе, структура — на выходе.

## Что на странице

**Плоскость.** Оценка против исполнения и закрытое против открытого пространство
вариантов. Навигация нарисована рамкой вокруг: это налог на размер портала, а не
пятый квадрант.

**Оси.** Десять координат, из которых считается рекомендация: инициатива,
темпоральность, делегирование, экспертиза, ставка, чувствительность данных,
внимание, веерность, единица управления, форма результата.

**Рекомендация.** Оценка каждой механики выводится из осей паттерна и штрафуется,
если тип экрана для неё не родной. Высокая ставка или персональные данные
включают правило: коммит остаётся кнопкой.

## Запуск

```bash
npm install
npm run dev
```

Откройте <http://localhost:43127>.

```bash
npm run build
npm run lint
npx tsc --noEmit
```

## Где что лежит

| Путь | Что там |
| --- | --- |
| `src/lib/patterns.ts` | Восемь паттернов и пять принципов |
| `src/lib/mechanics.ts` | Десять механик и формулы пригодности |
| `src/lib/axes.ts` | Плоскость и спектры |
| `src/components/plane-map.tsx` | SVG-плоскость |
| `src/components/axis-spectrum.tsx` | Шкала с маркером и призраком сравнения |
| `src/components/recommendation-panel.tsx` | Рекомендация механики |
| `src/app/page.tsx` | Композиция |

Стек: Next.js 16, TypeScript, Tailwind CSS v4, shadcn/ui. Графика на SVG и CSS.
